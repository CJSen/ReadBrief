# 常见问题

## 浮窗不显示 / 一闪而过？

请确认已为 ReadBrief 开启「**辅助功能**」权限（系统设置 → 隐私与安全性 → 辅助功能）。同时检查是否开启了「点击窗口外关闭」导致失焦即隐藏——浮窗显示后有 400ms 宽限期防止误隐藏，正常点击外部仍会关闭。

## 划词读不到选中文本？

部分应用（如 Safari）AX 属性不完整，会回退到 AppleScript 模拟 <kbd>⌘C</kbd> 复制兜底；若仍失败，可用托盘「**粘贴并总结**」走剪贴板路径——这条路径不需要任何系统权限。

## 打开时提示「无法验证开发者」/ 打不开？

当前为开发 / 免费阶段构建，尚未进行 Apple 公证（Notarization），属正常现象：

**安装包（.dmg）双击打不开**
- 前往 **系统设置 → 隐私与安全性**，滚动到底部「安全性」区域，点 **仍要打开**
- 或在终端解除隔离标记（将 dmg 文件拖入终端）：`xattr -cr <dmg 路径>`

**首次打开 App 提示「无法验证开发者」**
- **右键打开**：在「应用程序」中右键点击 `ReadBrief.app` → **打开**，弹窗中再次点「打开」
- **系统设置放行**：前往 **系统设置 → 隐私与安全性**，滚动到底部「安全性」区域，点 **仍要打开**
- **终端解除隔离**：`xattr -cr /Applications/ReadBrief.app`

后续配置 Apple 开发者证书并公证后，该提示即会消失。

## Windows 安装时 SmartScreen 拦截怎么办？

当前为开发 / 免费阶段构建，尚未使用 Authenticode 代码签名证书，属正常现象：

- 在 SmartScreen 拦截页点 **「更多信息」**，再点 **「仍要运行」** 即可继续安装
- 或在下载的 `.exe` 上右键 → **属性 → 常规**，勾选底部「解除锁定」后确定

配置代码签名证书（EV / OV）并签名后，该提示即会消失。

## 我的密钥安全吗？

密钥仅存于本地 `config.json`，且 AI 请求全部由 Rust 后端发起，前端渲染进程拿不到密钥。但 MVP 阶段本地为明文存储，请妥善保管本机；系统钥匙串加密在路线图中。

## 支持 Windows 吗？

支持。ReadBrief 现已发布 **Windows 版（x64，Windows 10 / 11）**，与 macOS 版功能一致：划词总结、三协议 AI、本地历史、提示词与快捷键管理全部可用。安装包为 NSIS `.exe`，下载页提供对应入口。

macOS 的 NSPanel 浮层为系统专属能力，Windows 端以置顶无边框窗口实现等效的「悬浮于任意应用之上、不打断工作」体验。

## 需要联网吗？

划词本身完全离线；只有在执行 AI 总结时才会请求你配置的 AI 服务（OpenAI / Claude / Gemini 或你的中转网关）。

## 总结会存到云端吗？

不会。所有历史记录只存于本机 SQLite（`~/Library/Application Support/ReadBrief/readbrief.db`），无账号、无云同步。

## 支持哪些 AI 模型？

只要你的服务商兼容 OpenAI / Claude / Gemini 任一协议即可，例如 `gpt-4o-mini`、`claude-3-5-sonnet`、`gemini-1.5-flash`，以及各类 OpenAI 格式的中转网关。

## 全屏看视频时浮窗会挡视线吗？

浮窗默认出现在光标附近，看完自动可关；也可以 <kbd>⌘</kbd><kbd>P</kbd> 固定后拖动到屏幕边缘。它是非激活面板，不会抢焦点、不会打断你的视频。
