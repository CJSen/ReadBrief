# 快捷键

## 全局快捷键（任意应用内可用）

| 功能 | 默认快捷键 | 说明 |
| --- | --- | --- |
| 划词总结 | <kbd>⌘</kbd><kbd>⇧</kbd><kbd>z</kbd> | 默认提示词，划词后提取要点与结论 |
| 呼出输入框 | 自定义 | 粘贴总结路径，无需权限 |
| 翻译并总结 | 自定义 | 翻译为中文，保留原意与语气 |
<!-- | 截图总结 (Pro) | <kbd>⌥</kbd><kbd>S</kbd> | 路线图能力，UI 已预埋 | -->

> Windows 端 <kbd>⌘</kbd> → <kbd>Ctrl</kbd>，<kbd>⌥</kbd> → <kbd>Alt</kbd>。

## 浮窗内快捷键

| 功能 | 快捷键 |
| --- | --- |
| 复制总结 | <kbd>⌘</kbd><kbd>C</kbd> |
| 重新生成 | <kbd>⌘</kbd><kbd>R</kbd> |
| 切换提示词 | <kbd>⌘</kbd><kbd>1</kbd> … <kbd>⌘</kbd><kbd>9</kbd> |
| 固定浮窗 | <kbd>⌘</kbd><kbd>P</kbd> |

## 录制式自定义

快捷键使用**录制式输入**（对齐 Bob / MASShortcutView 范式）：

1. 打开 **设置 → 快捷键**
2. 点击某条快捷键的「录制」按钮，进入监听态
3. 按下组合即录入（单独修饰键不计入）
4. 点击右上角「+」可新增自定义快捷键（需填写名称与说明）

录制控件右侧常驻 hint：绑定态为 ✕（清除绑定），录制态为 <kbd>Esc</kbd>（取消录制）。

### 键盘语义

- 纯 <kbd>Esc</kbd> → 取消录制
- 纯 <kbd>Delete</kbd> / <kbd>Backspace</kbd> → 清除绑定
- <kbd>Tab</kbd> → 透传
- <kbd>⌘</kbd><kbd>W</kbd> / <kbd>⌘</kbd><kbd>Q</kbd> → 取消并透传

### 冲突检测

冲突检测在失焦前完成，冲突项标红并**说明与什么冲突**（如「与系统聚焦搜索冲突」），而不是只说一句「冲突」。

## 绑定提示词与模型

每条快捷键可绑定**提示词 + 模型**：

- 提示词下拉：内置提示词 + 全部自定义提示词
- 模型下拉：从已配置的 AI 服务中选择（显示「服务名 · 模型名」）
- **模型由快捷键决定**，触发总结时使用该快捷键绑定的模型

::: warning 删除权限
内置三个快捷键（划词总结 / 呼出输入框 / 翻译并总结）不可删除；通过「+」新增的自定义快捷键可删除。
:::
