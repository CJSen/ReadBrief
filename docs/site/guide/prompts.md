# 提示词管理

提示词管理统一在**设置中心「提示词」页**承载（与主窗口为同一套界面），卡片式网格，自动填充排列。

## 内置提示词（不可改删）

| 提示词 | 默认绑定 | 说明 |
| --- | --- | --- |
| 总结提示词 | <kbd>⌥</kbd><kbd>D</kbd> | 默认提示词，划词后提取要点与结论 |
| 翻译提示词 | <kbd>⌥</kbd><kbd>T</kbd> | 翻译为中文，保留原意与语气 |
| 问答提示词 | — | 基于选中内容回答问题 |

内置卡片只提供「复制」操作，无编辑 / 删除按钮。

## 自定义提示词

- 支持**编辑 / 复制 / 删除**

## 变量语法

<code v-pre>{{text}}</code> 在提示词预览中用主色高亮，运行时替换为选中文本。

示例：

```text
请用简洁的中文总结以下内容，提炼 3 条要点和 1 条结论：

{{text}}
```

## 提示词与模型解耦

**提示词不与模型绑定。** 模型选择统一放在「快捷键」页：每个快捷键行在提示词下拉之后紧邻一个 AI 服务下拉（显示「服务名 · 模型名」）。由快捷键决定模型，而非提示词自身。

## 常见问题

**Q：内置提示词可以修改吗？**
A：不可以。内置三个提示词（总结 / 翻译 / 问答）不可修改、不可删除，这是产品承诺的稳定行为。
