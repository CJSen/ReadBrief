# 划词总结

## 划词总结（2 步）

1. 在任意应用（浏览器、PDF、IDE、备忘录……）里**选中一段文字**
2. 按全局快捷键 **<kbd>⌘</kbd><kbd>Shift</kbd><kbd>Z</kbd>**（可自定义），浮窗出现在光标附近，AI 开始流式输出

> **全屏也不怕**：无论你正全屏看视频还是写代码，浮窗都直接悬浮在当前页面，**不会切回桌面**。

## 粘贴总结（无需任何系统权限）

1. 按 **<kbd>⌥</kbd><kbd>A</kbd>** 呼出输入框（或在托盘菜单选「粘贴并总结」）
2. <kbd>⌘</kbd><kbd>V</kbd> 粘贴内容，回车即出总结

这条路径**不依赖辅助功能权限**，是某些读不到选区的应用里的可靠兜底。

## 浮窗操作

浮窗分上下两段：上半段为**划词/输入区**（最多显示两行，点「展开全文」手动展开），下半段为 **AI 输出区**。

| 操作 | 快捷键 | 说明 |
| --- | --- | --- |
| 复制总结 | <kbd>⌘</kbd><kbd>C</kbd> | 浮窗内随时可用 |
| 重新生成 | <kbd>⌘</kbd><kbd>R</kbd> | 换一种表达再来一次 |
| 固定 / 取消固定 | <kbd>⌘</kbd><kbd>P</kbd> | 固定后不响应 <kbd>Esc</kbd> |
| 发送 / 总结 | <kbd>Enter</kbd> | 输入框内；<kbd>Shift</kbd><kbd>Enter</kbd> 换行 |
| 切换提示词 | <kbd>⌘</kbd><kbd>1</kbd> … <kbd>⌘</kbd><kbd>9</kbd> | 快速换任务 |

**Esc 分层退出**：流式生成中按一次 = 停止生成（不关浮窗）；完成态按一次 = 关闭浮窗。固定态浮窗不响应。

## 错误处理

出错时浮窗**不显示笼统的「请求失败」**，而是按类型给出专属文案与解决按钮：

- **401 鉴权失败** → 检查密钥 → 「前往设置」
- **429 限流/额度** → 说明等待时长 → 「切换服务」
- **网络异常** → 检查代理 → 「重试」

## 历史记录

每次成功总结都会自动入库。打开主窗口可：

- 搜索、查看**原文 / 总结对照**
- 打标签、收藏、重新生成、删除
- 每条记录带 **AI 自动生成的小标题**（6–15 字），数百条历史也能一眼扫读
